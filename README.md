# Dapur Saluyu Website

Website landing page + katalog interaktif untuk Dapur Saluyu.

## Fitur
- Responsive desktop/mobile
- Animasi scroll reveal
- Floating food & leaf animations
- Cursor glow
- Scroll progress bar
- Active navigation berdasarkan section
- Tilt/parallax card interaction
- Filter menu
- Order builder interaktif
- Estimasi total otomatis
- Tombol lanjut ke WhatsApp
- Reduced-motion accessibility support

## Jalankan
Tidak perlu npm untuk versi ini.

Cara paling sederhana:
1. Buka `index.html` di browser.

Atau gunakan VS Code + Live Server.

## Ganti nomor WhatsApp
Buka `script.js`, cari:
`const whatsappNumber = "6281234567890";`

Ganti dengan nomor bisnis Dapur Saluyu dalam format internasional tanpa tanda `+`.

## Catatan
Foto makanan di folder `assets` berasal dari aset yang tersedia di percakapan. Beberapa foto digunakan sebagai placeholder untuk beberapa menu dan sebaiknya diganti dengan foto produk yang benar ketika sudah tersedia.
